# Milano Tour™

Gotowa strona na GitHub Pages.

## Publikacja
1. Utwórz nowe repozytorium na GitHub.
2. Wrzuć `index.html` oraz cały folder `assets`.
3. Wejdź w **Settings → Pages**.
4. Włącz Pages z gałęzi `main` / folderu `/root`.
5. Po chwili GitHub poda adres strony.

## Personalizacja
W `index.html` znajdź:
- `[IMIĘ]` — podmień na imię partnera.
- Możesz zmieniać teksty żartów w tablicy `stops`.
- Zdjęcia są w `assets/`.

Przycisk „Zobacz Street View” otwiera prawdziwy Google Maps Street View dla każdej lokalizacji.
